How it works

1

Publish on GitHub

Put your mod archive in a release on your own GitHub repository. It's free, with up to 2 GB per file.

2

Submit it here

Fill in a short form with the repo, description and requirements. It's checked automatically, with no waiting for approval.

3

Scanned and listed

Files are virus-scanned and their hashes recorded. New releases show up automatically.
