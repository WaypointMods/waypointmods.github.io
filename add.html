Leave your mark on the trail

Add your mod

Four short steps. Your files stay in your own GitHub repository; Waypoint only points the way. If the automatic checks pass, your mod goes live.

Which mod do you want to change?

You can change mods whose GitHub repository you own. New versions don't need this: publish a new GitHub release and Waypoint picks it up.

Where is your mod?

Paste the link to your mod's GitHub repository. We'll check it's ready before you fill in anything else.

Not on GitHub yet? How to get ready
  1. Make a free account at github.com.
  2. Create a new public repository for the mod. It can hold just a README; sharing your source is optional.
  3. Open the repository, select Releases, then Draft a new release.
  4. Create a tag with the version number, for example v1.0.0, and write the changelog in the description.
  5. Attach your mod archive (.7z, .zip or .rar, up to 2 GB) and select Publish release.

    Updating your mod

    Publish a new release in the same repository. Waypoint notices it within a minute and lists it once its files are virus-scanned, usually 2 to 5 minutes after you publish. You don't need to add it again.

    To change the name, description, screenshots, cover picture, category, games, tags, requirements, AI use, permissions, credits or virus scan, use Change your mod. Edits show within a few minutes.

    About replaced files. Every file's SHA-256 hash is recorded. If you replace a file in an existing release, it's scanned again like a new one. A file flagged by the virus scan hides the whole mod until it's looked at, and turning the scan off afterwards doesn't undo that.

    You can only add repositories you own. For a repository owned by an organization, make your membership of that organization public first.

    Rules

    Mods are listed automatically, so these rules are enforced through reports. Mods are removed for:

    • Reuploading someone else's mod without their permission
    • Sexually explicit content, which GitHub does not allow
    • Files that fail the malware scan, or unexplained executables in the archive
    • Paid mods. Everything listed here must be free to download. Early access is fine: you may give supporters a newer version somewhere else first, but if that version isn't released here for free within 3 months, anyone can report the mod.
    • Missing or misleading requirements
    • Hiding or misstating AI use
    • Using other people's work against their stated permissions
