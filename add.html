Add your mod

Your files stay in your own GitHub repository. This site only lists them, so you keep full control and nobody pays anything. There's no approval step: if the automatic checks pass, your mod goes live.

What you need

  • A free GitHub account
  • A public repository for the mod. It can hold just a README; sharing your source is optional.
  • A release with your mod archive attached (.7z, .zip or .rar, up to 2 GB per file)

1. Publish a release

  1. Open your repository on GitHub and select Releases, then Draft a new release.
  2. Create a tag with the version number, for example v1.0.0.
  3. Write the changelog in the description. It appears on your mod page.
  4. Attach your archive and select Publish release.

2. Add it here

The form asks for the repository, mod name, a one-line summary, the full description, category, supported games and requirements. It opens on GitHub. Automatic checks reply within a minute or two. If something needs fixing, the reply says what, and you edit the issue to try again.

How long until it shows? Usually 2 to 5 minutes after the bot's reply: the site rebuilds and your files are virus-scanned first. Files VirusTotal hasn't seen before take a few minutes longer while it analyses them. With no scan, it's about a minute or two. If you had the site open just before, press Ctrl + F5 to reload, because browsers can keep an old copy of the page for up to 10 minutes.

Optional extras:

  • Display name: the author name shown on the site, for example your Nexus name. Your GitHub account is always shown next to it.
  • Screenshots: drag or paste up to 8 images into the form. The first one becomes the cover picture. GitHub hosts them for free.
  • Virus scan: pick how your files are checked. Visitors see which one you picked.
    • Full scan with VirusTotal (recommended): 70+ antivirus engines. Files VirusTotal hasn't seen are uploaded to it, and its paid users can access them.
    • Private scan: ClamAV scans the file inside GitHub's build, and only its fingerprint is checked on VirusTotal. Your file never leaves GitHub, but brand-new malware is less likely to be caught.
    • No scan: nothing is checked, and your mod shows a red Not virus-scanned warning so visitors can decide for themselves.
    More about the scans

You can only add repositories you own. For a repository owned by an organization, make your membership of that organization public first.

3. Updating your mod

Publish a new release in the same repository. The site notices it within a minute and lists it once its files are virus-scanned, usually 2 to 5 minutes after you publish. Until then your mod page shows a "just released" notice. You don't need to add it again.

To change the name, display name, summary, description, screenshots, category, games, tags, requirements or virus scan setting, use the edit form. Edits show within a few minutes.

About replaced files. Every file's SHA-256 hash is recorded. If you replace a file in an existing release, it's scanned again like a new one. A file flagged by the virus scan hides the whole mod until it's looked at, and turning the scan off afterwards doesn't undo that.

Rules

Mods are listed without manual review, so these rules are enforced through reports. Mods are removed for:

  • Reuploading someone else's mod without their permission
  • Sexually explicit content, which GitHub does not allow
  • Files that fail the malware scan, or unexplained executables in the archive
  • Paywalled or "early access" files
  • Missing or misleading requirements
