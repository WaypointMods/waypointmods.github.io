About

A free place to list Skyrim mods, run by the community with no paid tiers and no ads.

How files are hosted

This site doesn't store mod files. Each author publishes their mod as a release on their own GitHub repository, and the download buttons here link straight to that release. Download counts come from GitHub.

The site itself is a set of static pages on GitHub Pages, rebuilt every few hours by GitHub Actions. That's why it costs nothing to run.

Safety

  • Every new file is checked against VirusTotal before it is listed. Files over VirusTotal's 650 MB limit are marked "not virus-scanned".
  • Each approved file's SHA-256 hash is recorded and shown on the Files tab, so you can check your download matches.
  • If an author replaces a file, the mod is hidden until a moderator reviews it again.
  • Anyone can report a mod from its page.

Takedowns and reports

If your work was uploaded without your permission, or a mod breaks the rules, open a report. Listings are removed while a report is looked into.

Questions

Does it work with mod managers?
Not yet. Downloads are manual for now: download the archive and install it with Mod Organizer 2 or Vortex as usual.
Why do I need a GitHub account?
Only authors and commenters need one. Downloading needs no account at all.
What happens if an author deletes their repository?
The mod drops off the site at the next rebuild and comes back if the repository returns.
How do I endorse a mod?
Star its GitHub repository. The star count is shown on the mod page.
Is this connected to Nexus Mods?
No. It's an independent, non-commercial project.
