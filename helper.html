Download with your mod manager

The Waypoint helper lets the Download with MO2 / Vortex button send a mod straight to your mod manager's downloads, like Nexus's "Mod Manager Download". It's free, small and open source, and you set it up once.

Set it up

  1. Download the helper (.zip)
  2. Extract the zip anywhere and double-click Install Waypoint Helper.cmd.
  3. Answer three questions: your mod manager (MO2 or Vortex), your game, and your downloads folder.
  4. On any mod page, press Download with MO2 / Vortex. The first time, your browser asks whether to open the link: allow it.
Windows may warn you when you open the .cmd file, because it was downloaded from the internet. Choose More info then Run anyway if you're happy with what it does (below). It needs no admin rights and only changes settings for your own Windows user.

What it does

  • Looks the mod up in Waypoint's own list, so a link can't point it at any other file.
  • Downloads the file from the author's GitHub release, and nowhere else.
  • Checks the file's SHA-256 fingerprint matches the one Waypoint recorded. If it doesn't, the file is deleted and you're told why.
  • Warns you and asks first if the file wasn't virus-scanned.
  • Puts the file in your downloads folder. For MO2 it also adds the mod name and version, so it shows up properly in the Downloads tab.
  • Then you install it in your mod manager as usual, including any install options the mod has.

The helper is a few short PowerShell scripts that come with Windows; nothing else is installed. Read them before running if you like: waypoint-helper.ps1, install.ps1, uninstall.ps1.

Change settings or remove it

To change your mod manager, game or folder, run Install Waypoint Helper.cmd again. To remove the helper completely, run Uninstall Waypoint Helper.cmd from the same zip. Mods you already downloaded stay where they are.

Good to know

  • Windows only, like MO2 and Vortex themselves.
  • Vortex: if a download doesn't appear in Vortex's Downloads page straight away, press Refresh there.
  • Prefer not to use it? The normal Download button always works. Drag the archive into MO2's Downloads tab or onto Vortex's Mods page.
